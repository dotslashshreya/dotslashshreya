## Building now: Skimora

**Founder & Software Engineer · [Skimora](https://skimora.net) · July 2026 – present · solo**

[Skimora](https://skimora.net) is a Chrome extension that makes reading easier for productivity-focused and neurodivergent readers, on web pages, PDFs and EPUBs. I designed and built all of it myself: the product architecture, the UI/UX system and the backend. **It launched in October 2026 and won its first 2 paying customers within a week.**

**Shipped:** bionic bolding, **Autopace** (a continuous reading guide that adapts its speed) and **Focus Mode**.

**Engineering highlights**
- **Fast rendering for large books:** virtualized PDF and EPUB rendering with pdf.js and epub.js, backed by a two-tier LRU / IndexedDB cache.
- **Private by design:** words-per-minute tracking with 90-day rolling reading-speed analytics, stored entirely on the reader's device.
- **Payments without accounts:** a serverless license-validation system on Supabase Edge Functions (Deno), with per-IP rate limiting and a schema secured by row-level security. Dodo Payments acts as Merchant of Record, so readers can buy a lifetime license without signing up.
- **Built to last:** I replaced a bolding algorithm duplicated across 5 modules with one shared tokenizer, now used by the web, EPUB and export pipelines. An event bus keeps each feature's domain isolated.

## Open-source spotlight

### [commaai/connect #947](https://github.com/commaai/connect/pull/947): every page and dialog is a link, and 5 navigation bugs are gone

[connect](https://github.com/commaai/connect) is comma.ai's React web app for managing openpilot devices and drives.

- **The problem:** navigation state flowed in two directions, from clicks to state to the URL and from Back/Forward to the URL to state. A flag threaded through 26 call sites kept the two from fighting. Dialogs such as Settings had no URL, so they couldn't be linked or reloaded.
- **What I changed:** the URL is now the only source of navigation state. One URL grammar is defined in a single place, with `parsePath` and `pathFor` tested as inverses. One `applyPath` function turns every location change into state. Dialogs became query parameters, so you can link to them and close them with Back.
- **How I verified it:** I wrote a failing test for each of the 5 bugs first. The suite grew from 96 to 102 tests, and app code got 85 lines shorter. Every commit passes lint, tests and the production build.

`React` `Redux` `JavaScript` `Testing` `Refactoring`
